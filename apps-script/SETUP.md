# 写真で採点：おとな用の設定手順

紙に書いた記述問題の答案を写真で送ると、Claude が読み取って採点するしくみの設定です。
PC を立ち上げておく必要はなく、採点は Claude Pro の枠で動きます。全部で15分くらいです。

```
お子さんのスマホ（GitHub Pages のアプリ）
   │ ① 答案の写真を送る　② 「まとめて採点する」を押す
   ▼
受付係（Google Apps Script・無料）── 写真を Google ドライブに保存
   │ ③ ルーティンを起動（渡すのは「受付の URL」と「その回だけ使える鍵」だけ）
   ▼
採点係（Claude Code のルーティン・クラウド）
   │ ④ 受付から写真を取りに行き、読み取って採点し、結果を受付に返す
   ▼
アプリが結果を受け取って表示（送ってから 2〜5 分）
```

採点係のルーティン「中1 記述問題の写真採点」は作成済みです。
https://claude.ai/code/routines/trig_01CcmiKpUUeqMYhmLT2KWuyW

---

## 1. ルーティンに API トリガーをつけて、URL とトークンをもらう

1. 上のリンクを開き、名前の横のメニューから **編集（Edit）** を選ぶ。
2. 「トリガーを選択（Select a trigger）」で **別のトリガーを追加（Add another trigger）** → **API** を選び、保存する。
3. もう一度 API トリガーを開くと、**URL**（`…/fire` で終わる）が表示される。これをコピーしてメモ帳などに貼る。
4. **トークンを生成（Generate token）** を押して、表示されたトークン（`sk-ant-oat01-…`）をコピーしてメモ帳に貼る。
   **トークンは一度しか表示されません。**
5. 編集画面のいちばん下の **コネクタ（Connectors）** が空になっていることを確認する。
   Gmail やドライブなどが入っていたら外してください（採点係には必要ありません）。

## 2. クラウド環境で Google Apps Script への通信を許可する

採点係はクラウドで動くので、受付係（Google）への通信を許可します。

1. ルーティンの編集画面で、「指示（Instructions）」欄の下にある雲のアイコン（**Default**）を押す。
2. 一覧の **Default** にカーソルを合わせ、右に出る設定アイコンを押す。
3. **ネットワークアクセス（Network access）** を **カスタム（Custom）** にして、**許可するドメイン（Allowed domains）** に次の2つを1行ずつ入れる。
   ```
   script.google.com
   script.googleusercontent.com
   ```
4. 「一般的なパッケージマネージャーのデフォルトリストも含める」にチェックを入れて、**変更を保存** する。

## 3. 受付係（Google Apps Script）をつくる

1. PC で https://script.google.com を開き、**新しいプロジェクト** を作る。名前は「中1中間テスト 写真採点」など。
2. 最初からある `コード.gs`（Code.gs）の中身を全部消して、このフォルダの **Code.gs を全部コピーして貼る**。
3. いちばん上の3行を書きかえる。
   ```js
   const PAGE_KEY = "…";       // 合言葉。自分で決める（英数字 12 文字以上の、わかりにくいもの）
   const ROUTINE_URL = "…";    // 手順1-3 の URL（…/fire）
   const ROUTINE_TOKEN = "…";  // 手順1-4 のトークン（sk-ant-oat01-…）
   ```
4. 保存（Ctrl+S）。
5. 右上の **デプロイ** → **新しいデプロイ** → 種類の選択（歯車）で **ウェブアプリ** を選ぶ。
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
6. **デプロイ** → **アクセスを承認** → 自分の Google アカウントを選ぶ。
   「このアプリは Google で確認されていません」と出たら、**詳細** → **（プロジェクト名）（安全ではないページ）に移動** → **許可**。
   （自分で作ったスクリプトなので問題ありません。ドライブへの保存と、ルーティンの起動に使う許可です）
7. 表示された **ウェブアプリの URL**（`https://script.google.com/macros/s/…/exec`）をコピーする。
   その URL をブラウザで開いて「OK: 写真採点の受付係は動いています。」と出れば成功です。

## 4. アプリに設定を入れる

1. https://komanechiman.github.io/chu1-chukan/ を開き、**写真で採点** → いちばん下の **おとなの設定** を開く。
2. 手順3-7 の URL と、手順3-3 の合言葉を入れて **保存** → **つながるか試す**。
   「つながりました。受付係の準備もできています。」と出れば OK。
3. **この設定のリンクをコピー** を押し、お子さんのスマホに LINE などで送って、そのスマホで開いてもらう。
   開いた端末に設定が入ります。**合言葉が入っているので、ほかの人には送らないでください。**

## 5. ためしてみる

1. 「写真で採点」で教科をえらび、紙に ①〜⑤ の番号をつけて答えを書き、写真を撮って送る。
2. 「まとめて採点する」を押す。2〜5 分で結果が出ます。
3. 1回目は、ルーティンのページ（上のリンク）の実行履歴で、採点のようすを見ておくと安心です。

---

## Code.gs を直したとき

**デプロイ** → **デプロイを管理** → 鉛筆アイコン → バージョンを **新バージョン** にして **デプロイ**。
URL は変わらないので、アプリの設定はそのままで大丈夫です。

## 困ったとき

| 表示・ようす | 原因と直しかた |
| --- | --- |
| 合言葉がちがいます | Code.gs の `PAGE_KEY` と、アプリの設定の合言葉を同じにする |
| 受付係にルーティンの URL とトークンが入っていません | Code.gs の上の3行を書いて、新バージョンでデプロイし直す |
| 今日の採点回数の上限に達しました | ルーティンは1日に起動できる回数に上限があります（Pro は発表時点で1日5回）。残りは https://claude.ai/settings/usage で確認できます |
| 採点係を起動できませんでした（401 など） | トークンがちがうか、再発行した。Code.gs の `ROUTINE_TOKEN` を直して新バージョンでデプロイ |
| 「採点中」のまま 20 分以上たつ | ルーティンの実行履歴を開いて確認。手順2 のネットワーク設定がないと、受付係につながらずに終わります。直したら、アプリで「採点をやり直す」を押す |
| 受付係につながりませんでした | 電波、またはアプリの設定の URL（…/exec）を確認 |

## しくみと安全のメモ

- 写真は、あなたの Google ドライブの「中1中間テスト 写真採点」フォルダに保存され、30 日たつと自動でゴミ箱に移ります。
- ルーティンに渡すのは「受付の URL」と「その回だけ使える鍵」だけです。ルーティンにはコネクタをつけていないので、Gmail やドライブなどには触れません。通信先も手順2 の2つのドメインに限られます。
- 採点のたびに、Claude Pro の使用量を使います（あなた自身の Claude の利用と同じ枠です）。
- トークンと合言葉は、Code.gs と、設定を入れた端末の中にだけあります。GitHub（公開されているアプリのコード）には入っていません。
- 採点係の指示文は `routine-prompt.md` にあります。ルーティンの中身を変えたいときの参考にしてください。
