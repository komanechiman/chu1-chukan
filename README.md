# 中1 中間テスト 500

中学1年・2学期中間テスト対策の4択クイズ。国語・数学・英語・理科・社会 × 各10単元 × 10問 = 500問、全問に解説つき。

## つかい方

- `index.html` を Chrome で開くだけ（ダブルクリックでOK）。ビルド不要。
- 教科 → 単元（10問）をえらんで解く。答えるたびに正解と解説が出て、最後に100点満点で採点。
- 単元の右の「解説」から、その単元の問題と答え・解説を一覧で見られる（答えは「＋」で開く）。
- 「ランダム10問」はその教科の100問からシャッフル。「まちがい復習」はまちがえた問題だけ（正解すると消える）。
- 「記述問題 5問」は答えを自分で書く方式。「答え合わせ」で模範解答・採点のポイント・解説が出る。
  - 数学：答え（数・式）を自動採点。全角数字や単位つき（「6個」「x=6」）も正解あつかい。式・考え方はメモ欄に書く（採点なし）。
  - 英語：模範解答と同じ文なら自動で◯。文は合っていても大文字・ピリオドを忘れると△。ちがう言い方は自分で採点。
  - 国語・理科・社会：自分で ◯（20点）／△（10点）／✕ をつける。採点のポイントに✓で目安を表示。
- 記録（単元ごとの最高点・まちがい帳・記述問題の最高点）はブラウザの localStorage に保存。
- 「写真で採点」：記述問題を紙に書いて写真を送ると、Claude が読み取って採点する（PC 不要・Claude Pro の枠）。
  写真はためておき、「まとめて採点する」で1回だけ採点係を起動する（ルーティンは1日の起動回数に上限があるため）。
  使う前に、おとなが一度だけ設定する → `apps-script/SETUP.md`

## ファイル

| ファイル | 中身 |
| --- | --- |
| `index.html` | アプリ本体（HTML / CSS / JS） |
| `data/*.js` | 教科ごとの問題データ（`[問題, [正解, 誤答×3], 解説, 本文?]`、正解は常に先頭で表示時にシャッフル） |
| `data/*.js` の `write` | 記述問題（`t`: num=自動採点 / en=英文 / text=自己採点、`accept`・`model`・`points`・`e`） |
| `manifest.json` | ホーム画面に追加する用 |
| `apps-script/Code.gs` | 写真採点の受付係（Google Apps Script）。写真の保存と、採点係（ルーティン）の起動・結果の受け渡し |
| `apps-script/SETUP.md` | 写真採点の設定手順（おとな用） |
| `apps-script/routine-prompt.md` | 採点係（Claude Code のルーティン）に渡している指示文の控え |

問題を直すときは `data/` の各ファイルを編集。`[[分子|分母]]` と書くと分数で表示される。

## 範囲の想定

一般的な公立中学の2学期中間（10月）を想定。学校・教科書で範囲がちがうので、テスト範囲表と見くらべて使う。

- 数学：正負の数（復習）・文字と式・1次方程式
- 国語：漢字・言葉の単位・文の成分・文節の関係・指示語と接続語・表現技法・詩・熟語・語句（教科書本文の読解は出していない）
- 英語：be動詞・一般動詞・複数形・代名詞・3単現・can・命令文・疑問詞・単語
- 理科：観察器具・植物と動物の分類・実験器具・物質の性質・気体・水溶液・状態変化
- 社会：世界と日本の姿・時差・都道府県・世界の気候と暮らし・アジア州・古代のはじまり
