# 中1 中間テスト 500

中学1年・2学期中間テスト対策の4択クイズ。国語・数学・英語・理科・社会 × 各10単元 × 10問 = 500問、全問に解説つき。

## つかい方

- `index.html` を Chrome で開くだけ（ダブルクリックでOK）。ビルド不要。
- 教科 → 単元（10問）をえらんで解く。答えるたびに正解と解説が出て、最後に100点満点で採点。
- 単元の右の「解説」から、その単元の問題と答え・解説を一覧で見られる（答えは「＋」で開く）。
- 「ランダム10問」はその教科の100問からシャッフル。「まちがい復習」はまちがえた問題だけ（正解すると消える）。
- 記録（単元ごとの最高点・まちがい帳）はブラウザの localStorage に保存。

## ファイル

| ファイル | 中身 |
| --- | --- |
| `index.html` | アプリ本体（HTML / CSS / JS） |
| `data/*.js` | 教科ごとの問題データ（`[問題, [正解, 誤答×3], 解説, 本文?]`、正解は常に先頭で表示時にシャッフル） |
| `manifest.json` | ホーム画面に追加する用 |

問題を直すときは `data/` の各ファイルを編集。`[[分子|分母]]` と書くと分数で表示される。

## 範囲の想定

一般的な公立中学の2学期中間（10月）を想定。学校・教科書で範囲がちがうので、テスト範囲表と見くらべて使う。

- 数学：正負の数（復習）・文字と式・1次方程式
- 国語：漢字・言葉の単位・文の成分・文節の関係・指示語と接続語・表現技法・詩・熟語・語句（教科書本文の読解は出していない）
- 英語：be動詞・一般動詞・複数形・代名詞・3単現・can・命令文・疑問詞・単語
- 理科：観察器具・植物と動物の分類・実験器具・物質の性質・気体・水溶液・状態変化
- 社会：世界と日本の姿・時差・都道府県・世界の気候と暮らし・アジア州・古代のはじまり
